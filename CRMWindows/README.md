# 私域 CRM Windows 版

独立 Windows 桌面版，使用系统自带 .NET Framework/WinForms 构建，不需要安装 Python、Node 或 .NET SDK。

本目录只包含 Windows 源码和构建脚本，不包含实际客户数据库。新电脑首次运行会在本机创建空数据库，用户数据不会写入 EXE，也不会随源码上传。

本目录与 `CRMApp/` 独立构建，Windows 工作流只读取本目录源码。

## 已实现

- 数据看板：本月/累计、成本、营业额、ROI、新单与二次漏斗、待跟进数量
- 客户：搜索、新增、编辑、删除、归属顾问、渠道、线索金额、体征、订单时间轴、一键复制全部资料
- 客户列表右键复制：右键任意客户行可单独复制客户姓名、电话或编号；右键会先切换到对应行，未录入的字段自动禁用
- 客户订单金额分栏：客户总览不再显示“订单数”和汇总“业绩”，改为按新单、二次至八次及多次分别展示有效订单金额；同一客户同一成交次数存在多笔订单时自动合计，支持横向滚动查看全部阶段
- 客户组合筛选：客户总览可按渠道、归属顾问及“全部客户/已开单/未开单”多条件叠加筛选，并与姓名、电话、编号、顾问搜索叠加；顶部实时汇总当前结果的客户数、有效订单数和业绩，便于核对各渠道及顾问产出回报
- 客户日期分组：录入日期固定在首列，默认按日期倒序；同一天客户使用轻微交替底色、细边框和组间距归为一组
- 单笔订单：新增、修改、作废/恢复、彻底删除、日期、成交次数、快递单号、单人100%/双人各50%
- 新发货建单：同步资料后按手机号匹配已有客户，检测未登记的快递单号并逐笔弹窗确认，日期、金额、顾问分配和快递单号均可校正后入库。订单只读取 `发货表.xlsx` 的“发货记录”工作表；`余文乐资料.xlsx` 只负责新增/补全客户，避免把 V06 小号等客户资料来源中的单号误判为订单
- 分析：近六个月 ROI 六行完整对比、渠道漏斗、地域、年龄和线索金额画像；表头固定 40 像素并垂直居中，各区块按真实行数展开并共用页面滚动条，不再截断数据
- 顾问：角色、小组、个人业绩、派发、新客户成交率、二次、ROI、15天未成交
- 顾问分配名单：客户、订单、新发货和流水确认统一读取配置顾问、当前客户归属及历史订单分配，并自动排除已离职顾问；旧备份缺少顾问配置时仍可从历史订单恢复可选名单
- 智能导入：支持 iOS 常用文本格式和制表符表格，先预览再入库
- 余文乐资料自动导入：每天 11:00、20:00 检测桌面 `余文乐资料.xlsx`；CRM 错过时段后首次启动会补检。按快递单号/资料指纹防重，已有手机号只补空字段，不覆盖手工数据
- 流水批量录入：支持“编号 + 次数 + 金额”连续模板，每笔强制确认客户、日期和分配，可暂存后补
- 历史分配：匹配同一客户时提示是否沿用最近一笔有效订单的顾问分配
- 数据安全：本地原子写入、导入前自动备份、iOS 明文 JSON 备份兼容
- 全局伪装工作区：从真实数据库复制独立副本；客户、订单、顾问、看板与分析均可在副本中修改，解除后立即恢复原始数据
- 显示保护：可单独隐藏营业额、成本、ROI、电话和地址
- 员工管理：改名会同步迁移客户归属、ROI 归属和订单业绩分配；删除后客户变为未分配，历史订单与业绩保留在“历史顾问”中
- 匹配保护：重复客户编号不会静默匹配第一条，流水导入会要求人工选择客户
- 解析保护：缺失渠道不会自动猜测为“食谱”，而是进入“需要核实”状态
- 性能与视觉：全局采用 Microsoft YaHei UI（不可用时回退系统界面字体）；彩色自绘控件统一使用 Windows ClearType 文本渲染，避免渐变、透明层和光晕导致文字发虚。页面按需刷新、绘图字体缓存、鼠标移动节流；看板卡片、分析区块、设置卡片、全部表格行和输入控件均有对应的悬浮、聚焦或选中反馈
- 桌面体验：左侧主导航、顶部上下文导航、125%/150% DPI 自适应；关闭窗口后进入系统托盘，可从托盘恢复或退出
- 可移植同步：一键同步脚本支持软件 `Scripts` 目录、用户“文档\\表格”目录或 `PRIVATE_CRM_SYNC_SCRIPT` 环境变量
- 看板下钻：ROI、资料成本、营业额、新单成交率、待跟进、销售漏斗、每日审阅和渠道概览均可点击查看明细；渠道概览按点击的食谱/直播/问答等渠道精确筛选，明细中可双击客户继续编辑
- 一键同步：使用 CRM 专用快速模式更新余文乐资料，跳过与 CRM 导入无关的快递上传模板、代收货款和额外报表；实测约 29 秒完成

## 数据位置

`%LOCALAPPDATA%\PrivateCRMWindows\crm_data.json`

自动导入配置和已处理资料指纹保存于 `%LOCALAPPDATA%\PrivateCRMWindows\auto_import_config.json`，与 CRM 主数据分离；可在“设置 → 余文乐资料自动导入”中开关、换文件或立即检测。

发货订单默认读取桌面 `杂项\自动更新发货 资料录入\发货表.xlsx`，同时兼容桌面同名目录和桌面根目录。按手机号匹配现有客户、按发货表快递单号防重；“代收”为 0 时仍会打开订单确认，由用户补录真实金额。取消会保留待确认状态，明确拒绝或成功保存后才停止提醒。

首次启用发货订单同步时会建立一次性历史基线：7 天以前的发货表单号按历史已处理，不再集中弹出旧订单；最近 7 天继续正常检查。弹窗选择“否”会永久忽略该快递单，“取消”才会在下次继续提醒。营业额/漏斗/每日审阅的订单明细首列显示客户编号，并提供快递单号、复制、直接编辑和删除单笔订单；删除订单只移除该笔成交及对应业绩，不删除客户或其他订单。

可在“设置 → 数据备份”中导入 iOS App 导出的明文 JSON 备份。
