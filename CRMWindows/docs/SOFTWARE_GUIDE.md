# 私域 CRM Windows 版：软件使用与维护说明

## 软件定位

私域 CRM 是一款本地优先的客户、订单、顾问业绩与 ROI 管理工具。Windows 版延续 iOS 版的主要数据结构，适合在电脑上批量导入资料、审阅数据、确认订单和查看经营分析。

软件默认不依赖云端数据库，核心数据保存在当前 Windows 用户的本地目录。退出、断网或外部服务不可用时，已经保存的客户和订单仍可查看。

## 主要功能

### 数据看板

- 本月与累计经营数据切换
- ROI、资料成本、营业额、新客户成交率
- 15 天未成交、暂未成交新单、暂未成交二次
- 每日审阅与渠道概览
- 点击指标进入对应客户或订单明细

### 客户档案

- 姓名、电话、编号、地址、体征、渠道、线索金额和归属顾问
- 按录入日期倒序并按天分组
- 搜索、新增、修改、删除和一键复制全部资料
- 订单时间轴、单笔订单修改、作废、恢复和彻底删除

### 经营分析

- 最近六个月 ROI 横向比较
- 渠道线索、新单率、复购率和营业额
- 地域、年龄与线索金额画像
- 页面统一滚动，表格按真实行数完整展开

### 顾问团队

- 顾问角色、小组和归属调整
- 个人派发、新单、成交率、二次、业绩与 ROI
- 顾问改名时同步迁移历史归属
- 删除顾问后客户转为未分配，历史订单业绩保留

### 智能导入与流水导入

- 支持制表符表格和常用中文文本
- 解析后先预览，再选择是否导入
- 缺少身高、体重、年龄或渠道时提示人工核实
- 流水模板支持“客户编号 + 次数 + 金额”连续录入
- 每笔流水可以确认客户、日期与顾问分配
- 重复客户编号必须人工选择，避免订单挂错客户

### 自动同步

- 默认每天 11:00 和 20:00 检测资料文件
- 文件同步失败后 10 分钟重试，不会把失败任务标记为完成
- 根据手机号、快递单号和资料指纹防止重复导入
- 已有客户只补充空字段，不覆盖手工修改内容

### 全局伪装工作区

- 开启时从真实数据库创建一份完整隔离副本。
- 伪装期间新增、编辑或删除客户、订单、顾问，只修改伪装副本。
- 看板、分析、顾问 ROI 和渠道统计会根据伪装副本实时重新计算，因此可以用于制作演示或截图。
- 伪装期间暂停自动资料同步和一键同步，避免把真实业务更新写进演示数据。
- 关闭软件后再次打开，仍会恢复上次的伪装工作区。
- 点击“解除全局伪装”后立即恢复真实数据库，伪装修改不会写回真实数据。
- 再次开启会从最新真实数据重新创建伪装副本。

## 托盘运行

点击窗口右上角关闭按钮时，软件进入 Windows 系统托盘继续运行，不会直接退出。托盘菜单支持：

- 打开私域 CRM
- 刷新数据
- 退出程序

需要完全关闭软件时，请使用托盘菜单中的“退出程序”。

## 界面与性能

- 默认使用 Microsoft YaHei UI，并在不可用时回退到 Windows 系统界面字体。实测它在当前 WinForms 与高 DPI 环境中比 Noto Sans SC 更稳定；幼圆不用于小字号正文，避免高密度表格笔画发虚。
- 彩色自绘控件、侧栏、子导航、按钮和看板卡片全部使用与系统表格一致的 Windows ClearType 文本渲染；光晕绘制在文字下层，避免渐变和透明层覆盖文字。设置卡片标题位于卡片内部，不再与边框交叠。
- 数据看板卡片在鼠标进入时会轻微浮起，边框逐渐变亮，并显示跟随指针的低强度光晕；分析区块和设置卡片使用同一套渐亮边框。
- 客户、分析、顾问和导入页面的表格支持整行悬浮高亮及左侧青色定位线；输入框获得焦点时表面同步提亮。
- 左侧导航、顶部子导航和主要按钮使用蓝紫渐变与液态高光表达选中、悬浮和按压状态。
- 鼠标光晕采用距离与帧率节流；绘图字体复用，避免持续移动鼠标时产生大量临时对象。
- 数据变化后只立即刷新当前页面，其余统计页在首次进入时按需刷新，减少大数据库下的无效重复计算。

## 数据与备份

主数据文件：

```text
%LOCALAPPDATA%\PrivateCRMWindows\crm_data.json
```

自动导入配置：

```text
%LOCALAPPDATA%\PrivateCRMWindows\auto_import_config.json
```

写入主数据时使用临时文件替换，并保留 `.bak` 备份。导入外部 JSON 前还会创建一份带时间戳的安全备份。

建议定期使用“系统设置 → 导出 JSON”复制到其他磁盘。不要直接使用文本编辑器批量修改正在使用的数据文件。

## 构建与测试

在项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File CRMWindows\build.ps1
CRMWindows\dist\PrivateCRM-Windows.exe --self-test
CRMWindows\dist\PrivateCRM-Windows.exe --ui-self-test CRMWindows\dist\ui-audit
```

构建产物：

```text
CRMWindows\dist\PrivateCRM-Windows.exe
```

## 使用边界

- 软件是本地个人工作工具，不提供多台电脑实时协同数据库。
- “显示保护”只隐藏敏感指标；“全局伪装工作区”允许修改隔离副本，两者都不会修改真实业务数据。
- 外部资料更新脚本属于可选的本机工作流；没有该脚本时，仍可手动选择 Excel 文件并立即检测。
- 若客户编号重复，系统不会自动猜测，应在订单确认弹窗中选择正确客户。
